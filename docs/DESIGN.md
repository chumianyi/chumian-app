# 初眠 · 设计基线
- 主题：真正 flutter_miuix 1.3.0，MiuixThemeController Monet 紫色种子 #6959EA。浅色/深色/跟随系统。
- 四个固定底栏：发现、分类、排行、我的，使用 MiuixNavigationBar。键盘出现时系统自动避让。
- 标题 26–30，卡片标题 16，正文 14–16，字距 0.3，行高 1.35；触控目标至少 48。
- 圆角 20–28 的 Miuix 卡片，图像 16:9；两列手机，三/四列宽屏。排行横向条目显示序号，不伪造热度。
- 搜索独立页面：自动聚焦、350ms 防抖、请求取消、输入历史、类别和最新/最热、分页。后台名称/简介统一 q。
- 原创月夜图仅用于品牌欢迎区；列表空态使用图标和解释，无虚构影片。
- 状态：首次引导、加载、无内容、离线、失败重试、分页失败、鉴权失效、播放器签名失效及下架。
- 动效：主题颜色过渡，卡片原库按压，原库底栏反馈；减少动效开关与系统 disableAnimations 合并。
- 播放器：黑色沉浸式区域，横屏全屏、控制锁、拖进度、倍速、弹幕开关；评论/简介在播放器下方。
- 生产边界：HTTP 提醒，授权媒体只同源带 Bearer；无下载、会员、用户投稿和管理员入口。
